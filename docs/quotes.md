# quotes（群友语录）

[← 总览](ARCHITECTURE.md)

---

## 功能

- **/新增群友 <昵称>**：添加要记录语录的群友。
- **/新增别名 <已有昵称> <别名>**：为已有群友添加别名。
- **/群友列表**：查看本群已记录的群友及语录数量。
- **/上传 <昵称> [图片]**：上传一条群友的发言截图；可引用含图消息；若昵称未存在则自动注册。
- **/截图上传 <昵称> <引用消息>**：引用一条消息，自动生成仿 QQ 聊天截图并保存为语录。
- **/查看 <昵称>**：随机查看该群友的一条语录。
- **/随机群友 [昵称]**：未指定则等概率随机一个有语录的群友再随机一条；指定则从该群友语录中随机。
- **/随机语录**：从本群全部语录中随机一条。
- **/随机精华**：从群精华消息中随机一条，格式「昵称：内容」。
- **/删除语录 <ID>**：仅超级管理员，按短 ID 删除语录。

## 实现要点

### 数据目录结构（按群隔离）

- `data/quotes/<group_id>/`
  - **members.json**：主昵称列表。
  - **aliases.json**：`{ "别名": "主昵称" }`。
  - **index.json**：`{ "short_id": { "member": "主昵称", "filename": "xxx.png" } }`。
  - **images/<成员名>/**：该成员的所有语录图片。

- 昵称解析：输入可为主昵称或别名，通过 `_resolve_name` 统一解析为主昵称。

### 短 ID

- 6 位字母数字，用于在列表中展示和删除；上传/截图上传时写入 index，删除时根据 ID 删文件并更新 index。

### 截图上传

- 引用消息 → 提取纯文本与 @ 展示名；拉取发送者头像；调用 **`yiyin.quotes.draw.async_generate_chat_screenshot(avatar_bytes, nickname, text)`** 生成仿 QQ 气泡截图（灰色背景、圆形头像、白色气泡、昵称+正文），保存到对应成员目录并写入 index。

### 随机精华

- 调用 OneBot `get_essence_msg_list` 获取精华列表，再对每条 `get_msg` 取内容；若消息已过期/删除则换下一条重试。

## 子模块 draw

- **路径**：`yiyin/quotes/draw.py`
- **作用**：聊天截图生成（无 NoneBot 依赖，可单独复用）。
- **实现**：Pillow 画布 + pilmoji 渲染正文（支持 emoji）；微软雅黑字体；自动换行、气泡与头像位置固定。
- **接口**：`generate_chat_screenshot(...)` 同步，`async_generate_chat_screenshot(...)` 异步（`asyncio.to_thread`）。
