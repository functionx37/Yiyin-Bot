# food（食物图鉴）

[← 总览](ARCHITECTURE.md)

---

## 功能

- **/收集食物 (名字) [图片]**：保存食物图片，可选名字；支持命令附带或引用含图消息。
- **/删除食物 <ID/名字>**：仅超级管理员；支持 ID 或名字；**引用食物消息可自动提取 ID**。
- **/补充名字 <ID/名字> <新名字>**：为已有食物补充或修改名字；**引用食物消息后发送 `/补充名字 新名字` 可自动提取 ID**。
- **/标记 <ID/名字> <标签>**：为食物添加标签；**引用食物消息后发送 `/标记 标签` 可自动提取 ID**。
- **/吃 <ID/名字/标签>**：吃指定食物；**引用食物消息可自动提取 ID**；若为标签则从该标签食物中随机一条；若为名字且重名则都吃。
- **/隐藏 <ID>**：将普通食物设为隐藏食物（仅管理）；**引用食物消息可自动提取 ID**。
- **/吃大餐 (数量)**：随机上菜，默认 3 道，最多 10 道；每条为『第 N 道菜：名字（id）』+ 图片。
- **吃什么**（关键词）：有人发『吃什么』时回复『是啊，吃什么』并随机一张图 + 『请你吃『名字』（id）怎么样？』。

## 实现要点

### 数据目录（按群隔离）

- `data/food/<group_id>/`
  - **index.json**：`{ "short_id": { "filename": "xxx.png", "name": "可选名字", "tags": ["标签1", ...] } }`。
  - **images/**：图片文件，文件名 UUID 等。

- 短 ID：6 位字母数字，与 quotes 类似的生成与索引逻辑。

### 图片获取

- 从命令参数或引用消息中提取图片 Segment，必要时通过 `bot.get_msg` 拉取原始消息中的图片并下载到本地。

### 展示格式

- 有名字：『名字』（id）；无名字：『id』。吃大餐与『吃什么』回复均按此格式。
