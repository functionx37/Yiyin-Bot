# magazine（群刊）

[← 总览](ARCHITECTURE.md)

---

## 功能

- **/群刊**：生成本群「群友语录 + 食物图鉴」的合并转发聊天记录，**每群每天限用一次**。

收到指令后先回复「群刊生成中…」，再按顺序发送：

1. **第一条**：群友语录（标题）
2. **第二条**：打包好的语录聊天记录（昵称：+ 对应语录图片，多条）
3. **第三条**：食物图鉴（标题）
4. **第四条**：打包好的食物聊天记录（名字或 ID + 对应图片，多条）

语录或食物过多时，会拆成多条合并转发发送（一般不会）。

---

## 实现要点

- **数据来源**：只读 `data/quotes/<group_id>/` 与 `data/food/<group_id>/`，与群友语录、食物图鉴插件共用数据。
- **每日限制**：`data/magazine/last_date.json` 记录各群上次生成日期，按自然日每群每天仅允许一次。
- **合并转发**：使用 OneBot `send_group_forward_msg`，单条转发最多 200 节点，超出则分段发送。
- **异常处理**：索引/图片读取失败仅跳过该条；发送失败时提示「群刊生成失败，请稍后重试」或部分发送说明。
